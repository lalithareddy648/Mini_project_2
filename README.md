# NovaPulse Smart Ring Landing Page

## Project Overview
This project is a modern, responsive product landing page for a fictional smart fitness ring called **NovaPulse**. It was developed as part of **Mini Project 2**.

The page is designed with a premium, sleek dark-mode aesthetic, utilizing vibrant neon purple and blue accents to convey cutting-edge technology and health tracking.

## Features Included
- **Navigation Bar**: Sticky header with an animated brand logo, desktop links, and a functional mobile hamburger menu.
- **Hero Section**: High-impact headline, floating product image (generated via AI), and prominent Call-to-Action buttons. Uses Flexbox.
- **Features Section**: Highlights three key features using a responsive CSS Grid layout and modern glassmorphism cards.
- **Benefits Section**: Split layout (Flexbox) explaining the product's unique selling points alongside a simulated UI element.
- **Testimonials Section**: Customer reviews displayed using a responsive CSS Grid.
- **Pricing & CTA Section**: Pricing details with a strong, gradient CTA button.
- **Footer**: Company links, social icons, and copyright information.

## Technologies Used
- **HTML5**: Semantic structure.
- **Tailwind CSS**: Rapid utility-first styling.
- **CSS3 (Custom)**: Keyframe animations for floating elements and entrance fades.
- **Flexbox & CSS Grid**: Advanced responsive layouts.
- **Vite**: Fast frontend build tool.
- **Vanilla JavaScript**: Minimal logic for the mobile navigation toggle.

## How to Run Locally
1. Ensure you have Node.js installed.
2. Clone this repository.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the Vite development server:
   ```bash
   npm run dev
   ```
5. Open your browser to the local address provided by Vite (usually `http://localhost:5173`).

## Responsive Design
The project uses Tailwind's mobile-first responsive utility variants (`md:`, `lg:`) to ensure optimal viewing on mobile phones, tablets, and large desktop monitors. CSS Grid columns automatically adjust based on the viewport width.
